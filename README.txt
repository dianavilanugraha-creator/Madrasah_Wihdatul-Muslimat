WEBSITE EDUKASI MADRASAH WIHDATUL MUSLIMAT

Isi website:
- Profil Madrasah Diniyah Takmiliyah Wihdatul Muslimat
- Tahun berdiri 2015
- No. Statistik MD 311231710023
- Jenjang I'dadiyah A, I'dadiyah B, Diniyah 1-4
- Kurikulum: Al-Qur'an, Aqidah Akhlak, Bahasa Arab, Fiqih, Hadist, Sejarah Kebudayaan Islam, Tauhid
- Wawasan pentingnya belajar agama untuk anak masa kini
- Dokumentasi Rihlah, Pesantren Kilat, KBM, dan Jumat Berkah bersama Es Teh Nusantara
- Galeri dengan filter JavaScript
- Form kontak dengan validasi JavaScript sederhana
- Instagram: @ywihdatul.muslimat

Catatan:
- Data mata pelajaran mengikuti informasi yang diberikan pengguna.
- Penjelasan umum tentang MDT dan kurikulum minimal merujuk pada sumber Kementerian Agama.
- Cek kembali data kontak sebelum website dipublikasikan.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html dengan Google Chrome.
3. Jangan pisahkan folder assets dari index.html, style.css, dan script.js.
